# Proyecto de Base de Datos

Proyecto pensado para ser un diseño completo de base de datos.

La intención de este proyecto es tener una base de datos previamente diseñada
con varias funciones útiles y queries ya escritas. La justificación de esto es
que en futuros proyectos —como algún homelab, un sistema, integraciones con
AWS RDS (Relational Database Service) o laboratorios controlados de
ciberseguridad— pueda utilizar esta DB como referencia. Este proyecto tiene
otro objetivo que es el de practicar bases de datos y demostrar conocimientos.

## Origen

Este proyecto nace de la curiosidad de aprender más sobre bases de datos. La
base del proyecto está tomada del último proyecto de bases de datos de mi
especialidad técnica.

## Libertad de uso

Cualquier persona que quiera usar esta base de datos para cualquier tipo de
implementación es libre de hacerlo. Ver [LICENSE](LICENSE) (MIT).

## Tecnologías

Este proyecto está hecho únicamente con SQL, pensado principalmente para el
motor MySQL.

## Estado del proyecto

El proyecto tiene datos de prueba, triggers y su schema, el proyecto
proyecto esta pensado para crecer según vaya aplicando nuevos conocimientos.
